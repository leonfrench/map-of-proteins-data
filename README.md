## Protein Neighborhoods - Data and data scripts

This repository contains all the data files (v6) required to render [protein neighborhoods](https://leonfrench.github.io/protein-neighborhoods/).

Also, the scripts used to make the map are here in the R and python notebooks folders. The ChatGPT prompt used is at the bottom of the GO_enrichment_of_clusters.R script. 

Like the [protein neighborhoods main repository](https://github.com/leonfrench/protein-neighborhoods) this is built upon the [Map of Github data repository](https://github.com/anvaka/map-of-github-data) by [Andrei Kashcha (@anvaka)](https://github.com/anvaka).
